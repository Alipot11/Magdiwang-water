Backup

Backups are stored on a computer in your office. Nothing is sent to a third party.

1. Full backup (recommended)

On the office computer that has this project installed, open a terminal in the project folder and run:

npm run backup

It saves a dated .sql file in the backups folder and keeps the newest 12. This is the file you would restore from. Copy it to a USB drive or a second computer.

2. Quick download (no setup)

Downloads all data as a single JSON file to this computer. It is easy to read, but it is a convenience copy; the full backup above is the one to rely on.

Keep it safe

Backup files contain residents’ names, addresses, payments and staff password hashes. Keep them in a locked folder or on an encrypted drive, make a copy at least weekly, and keep copies in two places.
